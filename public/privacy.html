Privacy policy

Everything is OK · yt.japharsworld.com and eiok.cc · updated 2026-11-03

In short: this site has no accounts, no cookies, no third-party analytics scripts and no ads, and it never asks for your VRChat name. It stores and logs which videos were found and played, under a room number, with no name attached. Your IP address can reach its logs only in the cases under Logs.

What this site keeps

  • Search results and plays. Video ID, public title, channel, length, whether live and the start of the description, under a room number and time, with no name or IP address. A pasted YouTube link's video is stored and logged the same way. No time limit: a result stays until its slot is reused, a room's last played video until its next play.
  • Video copies. With their video ID, quality, length, times and build details, nothing about who watched. Removed here 72 hours after their last upload, sooner when space is short. The home server keeps its copies until it needs the space.
  • Captions. Stored by video ID and reused for 7 days, then fetched again when needed. Old text is not deleted automatically.
  • Working files. Video IDs and Tunelio links of current and recent plays, and videos to send elsewhere for a while. Nothing about visitors.
  • Usage totals. Per day or hour, no end date: joins, searches, plays, captions, how many videos had captions, languages, quality picks, Channels redirects, video reports, how videos were served, and PC or Quest (from the software name or the form of the video's web address, not an IP address). Never search text, video IDs or IP addresses. Public VRChat numbers for the world and its group too.

Logs

Each request's kind, response code and duration. For a search: language, length, kinds of characters, PC or Quest. For plays, captions and reports: room number (instances can share one), ticket number, video ID, how it was served and the first 80 characters of the player's software name. No search text, IP addresses or VRChat account.

Exceptions: the firewall logs blocked packets' addresses, which can include visitors'. A rare search library warning can contain search text. Logs have no time limit; the oldest go only at a size cap. Until then, older web server log lines, written before this was changed, can still hold a visitor's IP address and full request address, including search text.

IP addresses in memory

Your IP address is held in memory when the search address loads (your search, or the world after you join) to stop request flooding. Only the last minute counts, but the entry can stay until that address returns, the list passes 10,000 addresses or the service restarts. Some plays also keep a hash of it and the player's software name in memory, to tell a reload from a new player. The service itself writes neither to disk.

YouTube API Services

This site uses YouTube API Services. By using this site, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

  • The only Google account connected is the world owner's own, which authorized access with the YouTube scope. That access is used for one thing: to keep the unlisted playlists behind the Channels list on the owner's channel current, by reading them, adding a live stream, removing the old one, or emptying one whose stream fails a safety check.
  • The monitor also reads public information about those streams: whether they are live, their titles and channels, viewer counts and thumbnails. It keeps that information to measure how reliable each stream is. These records and the access token are stored on one server run by the owner.
  • No private data about any other YouTube user is requested, stored or shared. Visitors never sign in to Google through this site.
  • The owner can revoke this access at any time in Google account permissions, after which stored access tokens stop working.
