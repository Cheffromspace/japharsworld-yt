Privacy policy

Everything is OK · yt.japharsworld.com · updated 2026-10-17

In short: this site keeps nothing that identifies you. It has no accounts, no cookies, no analytics and no ads.

Visitors of the VRChat world

  • Searches. When you search from the world, your VRChat client sends the search text to this server. The server asks YouTube for results and hands back a list of videos. Only the video IDs of the results are stored, for up to a day, so that others in the same instance can load the same video. The search text is not stored, the list is not linked to you, and it is overwritten as the server reuses its slots.
  • Logs. The server logs which kind of request it answered, the response code and how long it took. It does not log search text, IP addresses or anything about your VRChat account.
  • IP addresses. Your IP address is held in memory for one minute to stop request flooding. It is never written to disk.
  • Videos. Videos play straight from YouTube in your VRChat client, so YouTube receives your request as it would for any video. The Google Privacy Policy covers that.
  • Channels list. The world reads a public status file and a thumbnail picture from GitHub Pages. GitHub's privacy statement applies to those requests.

YouTube API Services

This site uses YouTube API Services, under the YouTube Terms of Service and the Google Privacy Policy.

  • The only Google account connected is the world owner's own, which authorized access with the YouTube scope. That access is used for one thing: to keep the unlisted playlists behind the Channels list on the owner's channel current, by adding a live stream and removing the old one.
  • The monitor also reads public information about those streams: whether they are live, their titles and channels, viewer counts and thumbnails. It keeps that information to measure how reliable each stream is.
  • No data about any other YouTube user is requested, stored or shared. Visitors never sign in to Google through this site.
  • The owner can revoke this access at any time in Google account permissions, after which stored access tokens stop working.

Sharing and keeping data

Nothing is sold or shared with third parties. Stream records and the playlist access token are stored on one server run by the world owner. Status alerts about streams go to the owner's private Discord channel.
